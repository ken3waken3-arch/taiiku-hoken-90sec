# 体育・保健体育｜変わること、引き継がれること、見直す理由

2026年10月5日公表の文部科学省「次期学習指導要領等に向けた審議まとめ」を根拠に、現行から引き継がれる点・今後変わる方向・見直しの背景を分けて解説するGitHub Pages向け静的サイトです。

## ファイル

- `index.html`：スマートフォン対応・検索可能な解説、MP4動画の実再生、字幕切替、検索、台本
- `styles.css` / `script.js`：レイアウト、動画表示、検索
- `配布資料.pdf`：引き継がれる軸・変更案・見直しの背景・授業提案をまとめたA4資料
- `90秒解説台本.txt`：6場面の更新版ナレーション台本
- `字幕.srt` / `字幕.vtt`：動画用字幕
- `assets/体育保健体育-変更点解説.mp4`：Canvaで書き出した約89秒、AI音声付きMP4（ローカル成果物）
- `assets/video-school-update-01.png` 〜 `06.png`：更新版動画スライド画像
- `体育_変更点解説_6枚_CANVA取込用.pptx`：更新版Canva取込用スライド
- `Canva動画化手順.md`：編集・音声・書き出し手順
- `公開手順.md`：GitHub Pages公開手順

## 編集方針

- 「引き継がれる軸」は現行から続く考え方を指します。
- 「変わる方向」は審議まとめに示された案であり、確定告示と表現しません。
- 「見直す理由」は資料に明記された課題を要約し、編集者の推測による因果付けを避けています。
- 授業例は資料の決定事項ではなく、方向性を具体化するための提案として区別しています。
