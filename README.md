# 体育・保健体育｜学校イメージ版

2026年10月5日公表の文部科学省「次期学習指導要領等に向けた審議まとめ」を根拠にした、GitHub Pages向けの静的サイトと動画用素材です。学校の体育館・保健の教室・授業後の振り返りを描いた新規ビジュアルに差し替えました。参考サイトのリンクは掲載していません。

## 成果物

- `index.html`：スマートフォン対応・検索可能な解説と、再生可能な6枚・約90秒のスライド
- `styles.css` / `script.js`：レイアウトとスライド・検索機能
- `配布資料.pdf`：A4縦1枚の印刷用資料
- `90秒解説台本.txt`：6場面のナレーション原稿
- `字幕.srt`：編集用の字幕ファイル
- `体育_学校イメージ動画用6スライド_改訂.pptx`：新しい写真風の授業場面を入れたCanva取込用スライド
- `assets/video-school-slide-01.png` 〜 `video-school-slide-06.png`：動画編集ソフトやWebサイトで使える16:9のスライド
- `assets/school-redesign/`：動画用背景画像
- `Canva動画化手順.md`：Canvaデザインと書き出し手順
- `公開手順.md`：GitHub Pages公開手順
